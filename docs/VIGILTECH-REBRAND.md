# Vigil Office rebrand

This branch carries the VigilTech visual and naming layer on top of the AltStack ecosystem source (Companion editors, Euro-Office editor build, Vigil Drive shared storage). Only names, brand assets, styles and packaging metadata differ from the ecosystem branch; server logic, API routes, data handling and editor integration are unchanged.

Needs migration (intentionally not renamed): `AltOffice/` folders in shared storage, `ao_session` cookie, `amerika-office` desktop executable and bundle ID `com.amerika.office`, `AltOffice-${os}-${arch}` release artifact names, `ALTSTACK_OFFICE_URL`, the `altstack/*` branch names and the `danecohn/AmerikaOffice` repository URLs, and the `altoffice` Euro-Office theme folder and image name.
